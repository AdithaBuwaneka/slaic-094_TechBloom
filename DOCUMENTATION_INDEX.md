## 🚀 Project Highlights (TL;DR)

### **What is Smart Transit Companion?**
An AI-powered transportation platform for Sri Lankan commuters featuring:
- **10 specialized AI agents** working together (LangGraph orchestration)
- **Mobile app** (React Native + Expo)
- **Admin dashboard** (Next.js 15)
- **Backend API** (FastAPI + MongoDB + Redis)
- **RAG chatbot** (ChromaDB + Google Gemini)
- **Real-time updates** (WebSocket)
- **Multilingual** (English, Sinhala, Tamil)

### **Key Numbers**
- **3** main components (Backend, Mobile, Dashboard)
- **10** AI agents
- **17** MongoDB collections
- **50+** API endpoints
- **8** transport modes
- **3** languages
- **12,000+** lines of code

### **Technology Stack**
- **Backend**: FastAPI, Python, LangGraph, MongoDB, Redis, ChromaDB
- **Mobile**: React Native, Expo, TypeScript, NativeWind
- **Dashboard**: Next.js 15, React 19, Tailwind CSS
- **AI**: Google Gemini 2.0 Flash, Groq, Langfuse

### **Competition (SLAIC 2025)**
- ✅ 10 AI Agents (Required: 7)
- ✅ Sri Lankan focus
- ✅ Community platform
- ✅ Real-time intelligence
- ✅ Production ready
