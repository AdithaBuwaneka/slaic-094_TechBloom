🤖 AI Agents Architecture

Our system employs 7 specialized AI agents that work collaboratively to provide intelligent transit assistance:

📊 Data Aggregation Agent

Collects real-time data from Sri Lanka Railways, SLTB/NTC buses, weather APIs, and traffic systems.

🛤️ Route Optimization Agent

Calculates optimal multi-modal routes considering time, cost, comfort, and accessibility factors.

⚠️ Disruption Management Agent

Monitors service disruptions and provides real-time alternative routing and notifications.

👤 Personalization Agent

Learns user preferences and provides customized recommendations based on travel patterns.

🌐 Language & Accessibility Agent

Handles multi-language translation and accessibility features for inclusive design.

💰 Fare Optimization Agent

Calculates optimal fares, identifies discounts, and suggests cost-effective payment methods.

🏘️ Local Knowledge Agent

Provides local insights, cultural context, and community-driven transit recommendations.

  • Live ETA Updates: Continuous arrival time adjustments
  • Weather Integration: Route adjustments based on weather conditions
  • Traffic Optimization: Real-time traffic consideration for bus routes
